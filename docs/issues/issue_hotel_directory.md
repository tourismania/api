## Контекст

Менеджеры агентства собирают офферы с одними и теми же отелями и каждый раз заново вводят описания
и ищут фото. Справочник отелей агентства с категориями номеров даёт диалогу отеля в оффере
подгрузить описание, фото и категории. Это первая половина задачи «отели оффера»; создание записей
справочника приходит со второй (`add-offer-hotels`).

**Инварианты:**

- **Отель принадлежит агентству и виден только ему.** Агентство берётся из текущей записи
  пользователя при каждом запросе; обхода для `ROLE_SUPER_ADMIN` нет; чужой отель неотличим от
  несуществующего (`404 hotel not found`). Читать может любой пользователь агентства.
- **Категория номера существует только у своего отеля**; у отеля может не быть категорий.
- **Создание — только доменная операция** (`hotel.New`, `hotel.NewRoomCategory`,
  `Repository.Insert*`), без эндпоинта: её вызывает сохранение оффера в своей транзакции. Роль
  фабрики не проверяют — права проверяет команда оффера.
- **Мягкое удаление** (`deleted_at`): все чтения фильтруют удалённые; категории удалённого отеля
  скрыты вместе с ним; эндпоинта удаления нет.
- **Общие правила полей** — `domain/content` (текст без управляющих символов, кроме `\t\n\r`;
  ссылки фото — абсолютные `http(s)` с хостом; звёзды 0–5), ими же пользуется позиция оффера.

## Эндпоинты

| # | Метод | Путь | Доступ | Успех |
|---|---|---|---|---|
| 1 | `GET` | `/api/v1/hotels?search=&limit=&offset=` | JWT, любая роль, своё агентство | `200` |
| 2 | `GET` | `/api/v1/hotels/{id}/room-categories` | JWT, любая роль, своё агентство | `200` |

1. Поиск по подстроке названия без учёта регистра, буквально (`%`, `_`, `\`); от 2 символов после
   нормализации пробелов, иначе `400 INVALID_SEARCH`; сначала начало названия, затем подстрока,
   внутри — название, `id`. Пагинация как у авиакомпаний. Элемент — `id, name, stars, address,
   description, photo_urls`, без категорий. `Cache-Control: no-store`.
2. Все категории в порядке создания, без пагинации: `id, name, description, photo_urls`. `{id}` не
   целое ≥ 1 → `400 invalid hotel id`; чужой, удалённый, несуществующий → `404 hotel not found`.
   `Cache-Control: no-store`.

## Non-goals

- Эндпоинты создания, изменения и удаления справочника; страница справочника в web.
- Связь отеля с городом и страной (адрес — текстом); общий для агентств справочник и импорт.
- Цены, даты и описания для клиента — данные позиции оффера (`add-offer-hotels`).
- Загрузка и хранение файлов фото.
