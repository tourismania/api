## Контекст

Комментарий менеджера к перелёту («багаж оплачивается отдельно», «ночная пересадка») — текст для
клиента рядом с ценой. Сейчас он есть только в редакторе web и теряется при сохранении: api его не
хранит. Без него web не может перейти на перелёты из api без потери данных.

**Инварианты:**

- **Комментарий — у перелёта целиком, не у сегмента.** Необязателен: отсутствие поля, `null` и `""`
  означают «комментария нет»; хранится и отдаётся как `""` (не `NULL`).
- **Текст — как есть.** Без обрезки пробелов, экранирования, разбора разметки; кавычки, `\`, `;`,
  `<>&`, эмодзи хранятся без изменений. Защита от SQL-инъекций — только параметры запроса (`$n`),
  склейка SQL со значением запрещена; «опасные» символы не фильтруются.
- **Управляющие символы запрещены**, кроме `\t`, `\n`, `\r`: C0 (`U+0000`–`U+001F`) и `U+007F` →
  `400` с `meta` `{"ManagerComment":"text"}` (доменный инвариант `flight.New`).
- **Длина — до 2000 символов** (руны, не байты) — правило формы запроса (`validate:"max=2000"`), как у
  `description` оффера; в БД `CHECK` нет.
- **Виден везде, где виден перелёт**, включая публичную ссылку.
- **Изменились только цена и/или комментарий — обновляются на месте.** Если в `PATCH` маршрут и время
  совпали, перелёты не пересоздаются, `id` сохраняются (`flight.DetailsUpdate`, `Repository.UpdateDetails`).

## Эндпоинты

Новых маршрутов нет.

| Метод | Путь | Что меняется |
|---|---|---|
| `POST`  | `/api/v1/offers` | у `flights[]` необязательное `manager_comment` (строка ≤ 2000, допускает `null`) |
| `PATCH` | `/api/v1/offers/{uuid}` | то же; правка только комментария сохраняет `id` перелётов |
| `GET`   | `/api/v1/offers/{uuid}` | у `flights[]` всегда `manager_comment` (строка, `""` — нет) |
| `GET`   | `/api/v1/public/offers/{uuid}` | то же |

## Ошибки

| Условие | Ответ |
|---|---|
| Длиннее 2000 символов | `400 validation failed`, `meta` `{"ManagerComment":"max"}` |
| Управляющий символ (кроме `\t\n\r`) | `400 validation failed`, `meta` `{"ManagerComment":"text"}` |
| Не строка (число, объект, массив) | `400 field "…" has the wrong type` |
| `manager_comment` в сегменте, `managerComment` у перелёта | `400` unknown field |

## Хранение

Миграция `019_add_offer_flights_manager_comment`: `offer_flights.manager_comment TEXT NOT NULL DEFAULT ''`;
уже сохранённые перелёты получают `''`. Совместима со старым кодом — можно накатить до выкладки.
Down — `DROP COLUMN` (теряются только комментарии).
