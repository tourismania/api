# Справочник валют: как добавить, изменить, удалить

Справочник валют — системные данные в коде, а не в БД: `internal/domain/money/currency.go`,
таблица `currencies`. У каждой валюты два поля:

- `Code` — код ISO 4217 (`RUB`, `USD`, …), три заглавные буквы;
- `Exponent` — число знаков после точки (minor unit по ISO 4217): RUB/USD/EUR/TRY — 2;
  TND, KWD, BHD, OMR, JOD, LYD, IQD — 3; JPY, KRW, VND — 0.

Суммы хранятся целым числом **минорных единиц** этой валюты (`price_minor BIGINT` + `currency CHAR(3)`),
на проводе — десятичной строкой. `Exponent` задаёт и разбор входа (знаков после точки — не больше
`Exponent`), и формат ответа (ровно `Exponent` знаков): `"12345.5"` RUB ↔ `1234550`, `"12.345"` KWD ↔ `12345`,
`"500"` JPY ↔ `500`.

Почему так, а не float или `NUMERIC`, — `FAQ.md`, раздел «Деньги и валюты».

Сейчас цену хранит только перелёт (`offer_flights.price_minor`, `offer_flights.currency`). Когда цена
появится у других позиций оффера, добавьте их таблицы в список ниже.

| Таблица | Столбец суммы | Столбец валюты |
|---|---|---|
| `offer_flights` | `price_minor` | `currency` |

## Добавить валюту

Миграция БД и правка swagger не нужны: `CHECK` на список валют в БД нет, в контракте `currency` — строка.

1. Сверьте код и число знаков с ISO 4217 — актуальная таблица на сайте SIX Group
   (<https://www.six-group.com/en/products-services/financial-information/data-standards.html>,
   «Current currency & funds code list»), столбец `Minor unit`.
2. Добавьте константу кода и строку в таблицу `currencies` в `internal/domain/money/currency.go`:
   ```go
   const CodeKWD = "KWD"
   // exponentThreeDecimals — три цифры после точки (у KWD — филсы).
   const exponentThreeDecimals = 3
   ...
   {Code: CodeKWD, Exponent: exponentThreeDecimals},
   ```
   Без магических чисел — для нового `Exponent` заведите именованную константу. Называйте её по
   числу знаков (`exponentTwoDecimals`, `exponentThreeDecimals`), а не по названию минорной единицы:
   у разных валют она называется по-разному (копейки, центы, филсы).
3. Тест в `tests/unit/money_test.go`: валюта находится `LookupCurrency`, сумма с `Exponent` знаками
   разбирается и форматируется обратно, лишний знак после точки отклоняется.
4. Прогоните тесты и линтер (см. `CLAUDE.md`, Validation Gates) в docker:
   ```bash
   go test ./tests/unit/... ./tests/application/...
   golangci-lint run
   ```
5. SDD (`tourismania/sdd`): список валют — часть спеки `offers/flights`. Заведите change
   (`/opsx:propose`) или правку спеки, сверьте список валют в web (`src/api/types/offer.ts`, тип `Currency`) —
   иначе web не даст выбрать новую валюту.

## Изменить число знаков после точки у валюты

Бывает при деноминации или если в справочнике ошибка. **Без миграции данных менять `Exponent` нельзя**:
суммы лежат в минорных единицах, и старые значения поменяют смысл — `1234550` при `Exponent` 2 это
`12345.50`, а при `Exponent` 3 — `1234.550`, в десять раз меньше.

Пусть Δ = новый `Exponent` − старый.

1. Проверьте, есть ли данные в этой валюте — по каждой таблице из списка выше:
   ```sql
   SELECT count(*) FROM offer_flights WHERE currency = 'XXX';
   ```
   Если строк нет — достаточно поменять `Exponent` в справочнике (шаги 4–6).
2. **Δ > 0 (знаков стало больше)** — пересчёт без потерь, умножение на 10^Δ:
   ```sql
   UPDATE offer_flights SET price_minor = price_minor * 10 WHERE currency = 'XXX'; -- Δ = 1
   ```
   Проверьте, что результат не выходит за `BIGINT` (при 10 цифрах целой части запас огромный).
3. **Δ < 0 (знаков стало меньше)** — деление на 10^|Δ| теряет младшие разряды. До миграции
   решите правило округления (обычно — банковское или вверх) и проверьте, сколько строк его затронет:
   ```sql
   SELECT count(*) FROM offer_flights WHERE currency = 'XXX' AND price_minor % 10 <> 0; -- Δ = -1
   ```
   Если таких строк нет — делите без округления; если есть — согласуйте правило с продуктом и
   отразите его в миграции явно.
4. Создайте миграцию `make migrate-new name=rescale_<code>_amounts` (одно действие — одна миграция);
   в up — пересчёт по всем таблицам из списка, в down — обратный пересчёт (для Δ < 0 down не
   восстановит отброшенные разряды — напишите это комментарием в файле).
5. Поменяйте `Exponent` в справочнике и тесты в `tests/unit/money_test.go`.
6. Выкатывайте миграцию **вместе** с кодом: старый код прочитает пересчитанные суммы с прежним
   масштабом. Откат — `make migrate-down` и предыдущая версия api.

Проверьте миграцию на копии данных: `make migrate-up`, `make migrate-down`, `make migrate-up`.

## Удалить валюту

Удалять можно, только если в данных её нет — иначе чтение таких цен сломается (`currency is not supported`).

1. По каждой таблице из списка:
   ```sql
   SELECT count(*) FROM offer_flights WHERE currency = 'XXX';
   ```
2. Если строки есть — сначала решите, что с ними делать (пересчитать в другую валюту, удалить
   позиции), и сделайте это миграцией.
3. Удалите строку и константу из справочника, обновите тесты, SDD-спеку и список в web — как при добавлении.
